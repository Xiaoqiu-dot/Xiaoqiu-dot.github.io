BUG 01 · TP 通信
BF16 Logit Gather 类型不匹配

rank 0 用默认 FP32 建接收 tensor，与各 rank BF16 输出 dtype 混用致 dist.gather 抛错 → 改用 torch.empty_like 继承 BF16。

BUG 02 · 显存生命周期
KV Cache 容量按错误峰值 OOM 误判

warmup 峰值混入编译期一次性分配 → 两次同步 warmup，第二次测稳态显存，容量只用稳态峰值。

BUG 03 · 多进程恢复
TP Worker 失败不回收泄漏显存

rank 0 异常后 rank 1 狂刷 Broken pipe → finally 销毁 process group + 幂等有界清理（SIGTERM → join → kill）。

BUG 04 · CUDA Graph
选错 batch 档 + Padding 污染 KV

取 min(graph_bs≥bs) 选最小合适档；replay 前清零 padding、slot_mapping 填 -1，只拷活跃 row。
