# Xiaoqiu-dot.github.io

胡亚坤 · 大模型算法工程师 — 个人主页，通过 GitHub Pages 部署。

访问地址：https://Xiaoqiu-dot.github.io

## 部署步骤

1. 在 GitHub 新建仓库，名字必须是 `Xiaoqiu-dot.github.io`（把 `Xiaoqiu-dot` 换成你的真实用户名），保持为空（不勾选 README / .gitignore / license）。
2. 在本目录执行：
   ```bash
   git remote add origin https://github.com/Xiaoqiu-dot/Xiaoqiu-dot.github.io.git
   git push -u origin main
   ```
3. 仓库 Settings → Pages，Source 选 `main` 分支、根目录 `/`，保存。
4. 等 1–2 分钟，访问 https://Xiaoqiu-dot.github.io。

## 说明

- 单文件 `index.html`，无任何依赖，加载极快。
- 深色 / 浅色主题切换（右上角，自动记忆）。
- Hero 终端打字动画、滚动淡入等交互，贴合算法工程师风格。
- 内容来源：个人简历（教育、实习、项目、技能、获奖）。

修改内容直接编辑 `index.html`，然后 `git add . && git commit -m "update" && git push` 即可更新网站。
